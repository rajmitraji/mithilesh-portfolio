## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/rajmitraji/mithilesh-portfolio.git

# Enter project directory
cd mithilesh-portfolio

# Install dependencies
npm install

# Start development server
npm start

# Build production bundle
npm run build
```
